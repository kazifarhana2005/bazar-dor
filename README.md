BazarDor is a dynamic market price website that helps users easily explore daily market prices in Bangladesh. Users can check the latest prices of essential products, including rice, lentils, oil, vegetables, fish, and meat, in one convenient place.

🔗 Live Site: https://bazar-dor-j924.vercel.app/

🚀 Technologies Used
Next.js – React framework for building the web application
TypeScript – Type-safe JavaScript development
Tailwind CSS & DaisyUI – Responsive and modern UI styling
MongoDB – Database integration
Better Auth – User authentication
REST API – Dynamic product and market price data
✨ Key Features
Daily Market Prices – Browse prices of essential products in Bangladesh.
Dynamic Price Updates – Display product prices and price changes, including increases and decreases.
Product Categories – Explore products by categories such as rice, lentils, oil, vegetables, fish, and meat, with price sorting.
Product Details – View individual product information, current prices, units, price changes, and market-wise prices.
User Authentication – Support user registration and sign-in with email/password and social authentication (Google and GitHub).
🎯 Project Goal

The goal of BazarDor is to make daily market price information more accessible and convenient for people in Bangladesh through a simple, user-friendly interface.
